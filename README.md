# 🌤️ SkyCast – Weather App

A simple Weather App built using HTML, CSS, and JavaScript that fetches real-time weather information using a Weather API.

### 🚀 Features
- Search weather by city name.
- Display real-time temperature and weather conditions.
- Simple and user-friendly interface.

### 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Weather API
